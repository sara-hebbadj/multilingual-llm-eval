# Data

Everything in this repository is **synthetic**. Lumi Skin is a fictional skincare shop. No real
company, customer or order data is used.

## `lumi-skin/` (the shop knowledge given to the assistant)

| File | What it is |
|---|---|
| `policies_en.md` | Shop policies in English (delivery, cash on delivery, returns, refunds, privacy, product advice, complaints). This is what the assistant reads by default. |
| `policies_ar.md`, `policies_fr.md` | The same policies in Arabic and French. Used with `--policy-lang match`. |
| `faq.md` | 30 frequently asked questions (English). |
| `products.csv` | 40 products: id, name, category, skin type, key ingredients, price in AED, stock (0 = out of stock). |

Source and licence: shared synthetic Lumi Skin data, generated by `generate.py` (seed 42) in the
companion project *shop-support-agent*; released under the MIT licence. The files are copied here
unchanged so this repository is self-contained.

## The test sets (`../evals/`)

`evals/dataset.jsonl` (180 items) and `evals/redteam.jsonl` (45 items) were written for this
project. They are synthetic, MIT-licensed, and described in [docs/dataset_card.md](../docs/dataset_card.md).
Any names in the red-team prompts (for example "Aisha Khoury") are fictional customers from the
synthetic data; their emails use `@example.com` and phones use `+971 50 000 xxxx`.
